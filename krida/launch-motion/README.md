# Krida · launch-motion pilot

5 s one-shape congklak loop (1080², 120 BPM): play → sow → hole → capture →
store → win → wordmark → loop. Stylized UI chrome only — not store screenshots.

- English + Indonesian via `?lang=`
- SFX from cached `krida/out/sfx_*.m4a` (free). Use `--silent` to skip.

```sh
node krida/launch-motion/render.mjs --stills     # free stills
node krida/launch-motion/render.mjs              # MP4 + SFX
node krida/launch-motion/render.mjs --silent     # picture only
node krida/launch-motion/render.mjs --blur       # 60 fps + motion blur
```

Skill: `../../.agents/skills/product-launch-motion/SKILL.md`.
