# Krida · launch-motion pilot

Silent one-shape congklak loop (4 s, 1080², 120 BPM beat grid) to prove the
`product-launch-motion` pipeline in Pamer Studio.

- Stylized UI chrome only — not App Store screenshots, not captured game frames.
- Real actions represented: play → sow → hole → store → win → wordmark → loop.
- English and Indonesian via `?lang=`.

```sh
node krida/launch-motion/render.mjs --stills     # free stills under krida/out/launch-motion/stills/
node krida/launch-motion/render.mjs              # silent MP4 preview
node krida/launch-motion/render.mjs --blur       # 60 fps + motion blur (slower)
```

Skill: `../../.agents/skills/product-launch-motion/SKILL.md`.
