# Coba Lagi: directory submissions

Drafted 2026-10-30, for 2.9.0. The user submits each one. Each listing uses its own campaign link (Results in `marketing-plan.md`). Claims come from the app repo's store listing. 2.9.0 went live on Google Play on 2026-10-30, so both store links work.

Budget is none, so take only what is free: if a site asks for money, stop and note it here.

## 1. AlternativeTo (free, quickest)

How: make a free account → user icon (top right) → "Suggest new application". It's reviewed before it shows. Then, on the pages of similar apps, "Contribute to this page" → "Suggest Alternatives" adds Coba Lagi there.

- **Name:** Coba Lagi
- **Website:** https://cobalagi.ardeman.com (store links: `alternativeto` under Results)
- **Short description:** A free coding game for kids aged 6–8, in Bahasa Indonesia and English, with picture blocks and spoken instructions.
- **Description:**

> Coba Lagi ("try again") teaches children the basics of coding through play. Kids put picture blocks in order to guide Koba the robot across nine planets, one idea per planet: directions, sequencing, loops, building their own block, looking ahead, saving steps, debugging, repeat-until and if/otherwise. Every instruction is spoken aloud in Bahasa Indonesia and English, so children who can't read yet can play; readers can type the same program as code.
>
> No ads, no tracking, no accounts, and it works offline. Free for one player. Open source under the GPL.

- **License:** Free, open source (GPL)
- **Platforms:** iPhone, iPad, Mac, Android, Windows, Linux, Steam Deck
- **Source code:** https://github.com/ardeman/project_cobalagi_flutter
- **Tags:** coding-for-kids, educational-game, programming, block-based-programming, offline, kids, puzzle
- **Suggest as an alternative to:** ScratchJr, Lightbot, Kodable, Code Karts, Box Island. Only on pages of coding games for young children.

## 2. Educational App Store (submitting is free; certification may not be)

How: https://educationalappstore.com/developer → "Submit your app". Its site says submitting is free, but gives no price for certification. If they quote a fee, don't pay it; note it here and ask the user.

- **App name:** Coba Lagi: Learn to Code
- **Category:** Computing / Coding, ages 6–8
- **Links:** App Store and Google Play campaign links for `edappstore` (Results), website.
- **Description:** the AlternativeTo description above, plus:

> What children learn: putting steps in order, loops, functions (their own block), conditions (look ahead, if/otherwise), variables (step box), repeat-until and debugging. After every puzzle the app picks what comes next: the next planet, a generated practice puzzle (always checked to be solvable) or a review of an earlier skill. Mistakes are met with encouragement, and the block that caused a bump is marked.

- **Data and safety:** no data collected (App Store privacy label: Data Not Collected), no ads, no accounts, no internet connection, parent area behind a grown-up question, purchases only from the parent area. Privacy policy: https://cobalagi.ardeman.com/privacy.html
